# ぶーぶー どらいぶ 🚗

幼稚園児向けの、かんたん操作で楽しく遊べる車の運転ゲームです。

## あそびかた

`index.html` をブラウザで開くだけで遊べます(インストール不要・スマホ/タブレット/PC対応)。

1. すきな色の車(あか・あお・きいろ)をタップしてえらぶ
2. ゆびでドラッグ(またはタップ・矢印キー)で車をうごかす
3. ⭐ や くだもの(🍎🍌🍓)をあつめる
4. 10こあつめるたびに 🎉 おいわい!

## とくちょう

- **ゲームオーバーなし** — コーン(🚧)にぶつかっても「ぼよん」と楽しい音が鳴るだけ
- **かんたん操作** — ドラッグひとつ。キーボード(←→)でも遊べます
- **文字はぜんぶひらがな** — 小さい子でも読めます
- **効果音つき** — Web Audio で生成(外部ファイル不要)。右上の 🔊 でオン/オフ
- **1ファイル完結** — 依存ライブラリなし、`index.html` だけで動きます
